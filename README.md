# Stack Data Structure Tutorial

This repository contains a simple demonstration of Java's Stack data structure, created for educational purposes.

## 📺 YouTube Tutorial

Watch the full tutorial here: [Stack Data Structure Tutorial](https://www.youtube.com/watch?v=DPYBIbeUjY0)

## 📋 Overview

This project demonstrates the basic operations of a Stack data structure in Java, including:
- Creating a new stack
- Checking if the stack is empty (`isEmpty()`)
- Adding elements to the stack (`push()`)
- Viewing the top element without removing it (`peek()`)
- Removing and returning the top element (`pop()`)

## 🚀 Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- Any Java IDE (IntelliJ IDEA, Eclipse, etc.) or a text editor

### Running the Code

1. Clone the repository:
```bash
git clone https://github.com/enesgunumdogdu/Stack-Youtube.git
cd Stack-Youtube
```

2. Compile and run:
```bash
javac src/Main.java
java -cp src Main
```

## 📖 What is a Stack?

A Stack is a Last-In-First-Out (LIFO) data structure where:
- Elements are added (pushed) to the top
- Elements are removed (popped) from the top
- Only the top element is accessible at any time
